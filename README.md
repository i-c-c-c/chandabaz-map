# 🗺️ 2D Road Exploration Map

A simple 2D interactive map featuring a controllable yellow block as the player character. The player can move around the map, explore the environment, and navigate roads surrounded by buildings.

## 🎮 Project Overview

This project is a basic 2D map exploration prototype designed to demonstrate player movement and environmental navigation.

The map features a road with buildings placed along its sides, while a yellow rectangular block acts as the controllable player.

## Features

- **2D Map:** A top-down view of an environment.
- **Player Character:** A yellow block representing the player.
- **Player Movement:** Move freely around the map.
- **Road System:** Roads forming the main navigation paths.
- **Buildings:** Structures positioned alongside the roads.
- **Map Exploration:** Navigate and explore the environment.

## 🎮 Controls

| Key | Action |
|---|---|
| W / ↑ | Move Up |
| S / ↓ | Move Down |
| A / ← | Move Left |
| D / → | Move Right |

## 🏙️ Map Design

- Perspective: 2D Top-Down.
- Player: Yellow rectangular block.
- Environment: Roads and roadside buildings.
- Navigation: Keyboard-controlled movement.
